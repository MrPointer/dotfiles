# Project Constitution

`.specify/memory/constitution.md` is fixed Spec Kit infrastructure. The
project's canonical governance lives in its applicable `AGENTS.md` files, not
in this file.

Before continuing, you **MUST** read every applicable root and nested
`AGENTS.md` file using the active agent harness's normal scope and precedence.
Treat those instructions as project governance for this workflow.

You **MUST** also read `.specify/memory/constitution.local.md` when it exists.
That file may contain only Spec Kit-specific additions or overrides. A local
rule takes precedence for the Spec Kit workflow when it conflicts with
`AGENTS.md`, but you **MUST** report the conflict explicitly.

Report the governance sources read, duplicate or contradictory rules, and any
missing source. If neither source provides governance, continue only when the
current phase permits it and report that no project governance was found.

You **MUST NOT** modify any `AGENTS.md` file, modify this constitution, copy
`AGENTS.md` contents into this constitution, or invent missing governance.
